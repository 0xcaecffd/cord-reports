Summary#

In late October 2026 a gamer's Steam and Discord accounts were taken over at the same time. Both accounts were then used to message the owner's contacts. Five images were sent: one through Steam and four through Discord. We collected the images and followed everything they lead to.

The images contain no malware. Each one is a social-engineering lure, and they lead into two separate operations.

  1. A Steam credential-phishing service (lane 1). The Steam image is a fake "$100 gift card" with a QR code. The QR code opens a look-alike of steamcommunity.com that shows a fake Steam sign-in box. The page is one tenant of a phishing-as-a-service platform: each page carries an affiliate ID, and at least two affiliates share the servers. The same servers also act as the command server for at least 16 malicious Windows programs that pose as Steam. Some are small fake Steam windows built on WebView2. Others are 61 MB installers that unpack a fake Steam app built on Electron, which steals credentials and sends them to two further domains. Hosting, language artefacts and a lure upload under a Russian file name point to a Russian-speaking operator.
  2. A MrBeast crypto-casino deposit scam (lane 2). The four Discord images are a scripted story: a fake MrBeast post announces a casino bonus, a user activates the code, withdraws $3,700, and shows the money arriving in a wallet. The casino domain is one of at least 25 near-identical sites on one server, each lasting a few days. The images carry deliberately broken EXIF data so that every copy has a different file hash, which defeats hash-based spam filtering.

We found no technical link between the two lanes. They share only the hijacked accounts. That fits stolen sessions being sold or rented to more than one scammer.

If you received these images: do not scan the QR code and do not visit the casino. If you already did, follow Recovery and cleanup. If your own account sent them, start there too: your Steam and Discord sessions are in someone else's hands right now.

Key findings#

  • The Steam phish does not use a plain password form. It shows a fake Steam sign-in box inside the page, sets a signed cookie that names the affiliate who owns the link, and posts an encrypted record of the visit back to its server. Treat any password typed into it as stolen.
  • The phishing host 8909451279.f1shh[.]at serves a phishing page and is also the command server for three of the fake-Steam programs. Phishing and malware run on one platform, not merely on shared hosting.
  • A 61 MB installer in the same set unpacks an Electron app whose package.json claims to be "steam-login-app" by "Valve Corporation". Its logic is hidden as compiled V8 bytecode (bytenode). It opens target sites in a window with Node access, injects CSS and JavaScript, and uploads what it collects to fakefake[.]shop and pulse-keys[.]store.
  • The casino lure images reuse a phrase from the casino site itself ("Your Withdrawal of $3700.00 Was Successfully!"), so the screenshots came from the real scam kit, not a mock-up.
  • How the account owner was first compromised is not proven. An infostealer taking both platforms' sessions at once fits best (medium confidence). Password reuse, or a phish like the one the account then sent, also fit.

How the lures reached people#

Both hijacked accounts sent the images to existing contacts, which is what makes the lures work: they arrive from a friend. Neither message contained a clickable link. The Steam lure hides its URL in a QR code, and the Discord lure spells the casino name out inside a screenshot. Link scanners on both platforms check text, not pixels, so neither lure gives them anything to block.

Lane 1: the Steam phishing service#

The lure#

The gift-card image shows real game art (Elden Ring, Baldur's Gate 3, Cyberpunk 2077, Starfield, Minecraft) around a Steam logo, with "TAKE YOUR FREE $100 GIFT CARD" above a QR code. The code decodes to hxxps://steamcomrnuunity[.]com/code/2035922. The domain swaps the m in "community" for rn, which reads as m at a glance, and doubles the u. The /code/<number> path imitates a gift-card redemption link.

The image was hosted on Steam's own user-content CDN at one point (one of its VirusTotal submission names is images.steamusercontent.jpg). Another submission used a Russian file name meaning "Untitled.jpg". It was first submitted on 2026-10-11, one day after the phishing URL's first public scan.

The landing page and sign-in box#

The domain's root returns a 404 page. Only the /code/<id> paths show the lure, which keeps the site looking empty to anyone who browses to the bare domain. Four codes were observed: 2035922, 647829, 876809 and 3454765444. One shows a $50 card and the others a $100 card. VirusTotal lists at least ten flagged paths on the domain, including /code/, /activate/ and long hex paths that change per visitor.

The page shows a Steam-styled landing screen with a fake counter of cards "received". Its "Get the card" button calls an openAuth() function in the page script. That function builds an iframe holding a Steam-styled sign-in dialog (password, Steam Guard code or QR sign-in) inside the phishing page. The server sends X-Frame-Options: ALLOWALL and frame-ancestors *, so the kit can also be framed by other sites.

We read the page script but did not run it, and we never submitted anything to the form. So we cannot say whether the dialog relays a live Steam sign-in or only records what is typed. Either way, treat any password, Steam Guard code or QR approval given to this page as stolen.

The same platform's malware#

VirusTotal links 16 Windows programs to the main phishing server. We downloaded all of them for static analysis and ran none. They fall into two families of fake Steam apps.

Fake Steam windows (WebView2), 11 samples#

Eleven are 1 MB 64-bit programs, nearly all named steam.exe or Steam.exe. When they run they copy themselves under random names such as C:\Windows\q3e342g.exe. One used the real Steam install path, C:\Program Files (x86)\Steam\steam.exe. Ten share the same five bundled files, so they come from one builder. They were first submitted to VirusTotal between 2026-09-21 and 2026-10-17. Detection ranges from 3 to 40 engines.

We analysed a representative (f27af032…, 40 detections) in depth. What it does:

Takes a single-instance lock, so a second copy waits for the first to exit.
Writes a second program, carried as a 164 KB resource (RCDATA 300), to disk.
Opens a frameless, dark, DPI-aware window built on Microsoft Edge WebView2, styled like a Steam sign-in. It stays hidden for 1.5 seconds, then appears in front.
Loads its page from hxxps://8909451279.f1shh[.]at/client, the same phishing host we fetched.
Gives that page a JSON message bridge to native code. Through it the page can read any file by path, write any file, and open URLs or programs.
Builds a machine fingerprint from the process ID, tick count and locale, mixed with fixed XOR constants, and sends it with its web requests (WinInet, 15 s and 30 s timeouts).

The result is a remote-controlled credential trap. The operator's server decides what the window shows, and the bridge lets that page read and write files on the machine. That covers Steam's local session files as well as browser data. The dropped second program was not analysed in this pass.

Fake Steam installers (NSIS and Electron), 5 samples#

Five 61 MB files are NSIS 3 installers, with 0 to 2 detections. They are built in three layers:

NSIS installer. Stock NSIS code. Its version info and icon pose as Valve. It unpacks a 63 MB 7-zip archive and starts the payload with no window (CREATE_NO_WINDOW).
Electron app. A renamed Chromium/Electron runtime with an app.asar. Its package.json says "name": "steam-login-app" and author "Valve Corporation". The 44-byte main.js just loads main.jsc through bytenode.
Compiled payload. main.jsc is 93 KB of V8 bytecode, which hides the source. Its strings show a BrowserWindow with Node integration on and context isolation off, a TARGET_URLS list, injected CSS and JavaScript in a dark Steam-like theme, browser storage and service-worker access, and two upload endpoints: hxxps://fakefake[.]shop/3253523 and hxxps://pulse-keys[.]store/6887.

This is the same idea as the WebView2 programs, rebuilt on Electron: a convincing Steam window that the victim signs in to, with full access to the machine behind it.

How the malware is probably delivered#

We did not find the download pages. The evidence points to game-related lures: the cheatdetector[.]shop domain on the same server, programs named SteamClient.exe, and one sample's build path 12rwqr-main/DWASDAS/SteamClient.exe, which looks like the author's own project folder. Fake "cheat detectors", game cheats and "Steam client fixes" sent over Discord are the usual route for this kind of malware.

Lane 2: the MrBeast crypto-casino scam#

The four-image story#

The pattern is a deposit scam. The bonus can only be "withdrawn" after a deposit or a "verification" payment, and that money is gone. The withdrawal and the wallet receipt were staged to make the payout look real.

Hash-busting images#

All four Discord images carry the same deliberately broken EXIF block: a 94-byte APP1 segment whose six fields point outside their own data. Orientation has a count of 2 and XResolution a count of 8. The comment field varies per image ("Exported from Photos", "Processed by MediaService", "Compressed by imaging-sdk", "Quality: standard"). None of this changes the picture, but every copy gets a different file hash. None of the four hashes we received has ever been seen on VirusTotal. That shows how well it works against "block this known image" filters.

The casino farm#

The casino in the images, marewin[.]com, was registered at Dynadot on 2026-10-23 and put on clientHold about three days later. It sat on 172.86.88.161 (RouterHosting / Cloudzy, AS14956) beside at least 24 sister sites built from the same template, titled "{Name}: Crypto Casino & Provably Fair Games":

amkwin, basoowin, fabawin, hudowin, jolyspin, kegwin, kevowin, kigwin, mavubet, mazowin, meviwin, mosubet, padowin, pevowin, ruzowin, tasowin, uvowin, vadowin, vazowin, xakawin, zenawin, ziewin, zuzawin, zytwin (all .com)

Archived copies show a self-contained Next.js app with no analytics, no third-party scripts and no wallet addresses in the page. It accepts USDT, USDC and BNB. When we checked, HTTPS no longer worked on any of the sites, and plain HTTP to the server answered 503. The farm moves on to new names faster than registrars suspend them.

The setup resembles kits sold as a service for this kind of scam. We looked for one published kit's tell-tale API path (/api/mammoth/chat) and did not find it, so we do not name a kit.

Detection#

Network#

Block the domains and IPs in the indicator list. For broader coverage, block or alert on new lookalikes of steamcommunity.com and steampowered.com, and on any HTTPS to AS214351.

Host#

Look for:

  • Any steam.exe or Steam.exe outside C:\Program Files (x86)\Steam\, especially under C:\Windows\ with a random 5 to 9 character name.
  • Unsigned programs that host an Edge WebView2 window, import WinInet and carry a PE file as resource RCDATA 300.
  • An Electron app whose resources\app.asar contains package.json with "name": "steam-login-app", or a main.js that only requires bytenode and a main.jsc.
  • NSIS installers around 61 MB with Valve version info that are not signed by Valve.
  • Traffic to any numbered subdomain of f1shh[.]at.

YARA#

CORD's rule for the WebView2 group matches all 8 of its core members and 2 close relatives (10 of the 16 programs). The rule for the installer group is still being written. Both will be published here as YARA once they pass measurement.

Recovery and cleanup#

This section is for anyone whose account sent these lures, and for anyone who scanned the QR code, signed in on the fake page, or ran one of the programs. Steam and Discord are both confirmed compromised in this case, so do all of it.

Use your phone or another clean device for every account step. If the PC is infected, it will steal new passwords as you type them. Do not wait for the PC to be cleaned before securing the accounts: until every session is logged out, the attacker is still inside.

Right now#

  1. Take the affected PC off the network (unplug it or turn off Wi-Fi).
  2. From another device, warn your contacts on Steam and Discord: your account was hijacked, recent images and links from you are scams, and anyone who scanned the QR code or signed in should follow this guide.

Secure your email first#

Email resets every other account.

  1. Sign out of all other sessions.
  2. Change the password to a new one you have never used. A password manager makes this easy.
  3. Turn on two-factor sign-in with an authenticator app or a passkey.
  4. Check the recovery phone number and recovery email.
  5. Remove any forwarding rules or filters you did not create.

Steam#

  1. Change the password at store.steampowered.com (Account details).
  2. Go to store.steampowered.com/twofactor/manage and choose Deauthorize all other devices. This ends the attacker's session.
  3. Make sure the Steam Guard Mobile Authenticator is on. Re-link it if anything about it changed.
  4. Check the Web API key page at steamcommunity.com/dev/apikey. If a key exists that you did not create, revoke it. Hijackers register keys to watch and redirect your trade offers, and the key survives a password change.
  5. Check that the email and phone on the account are still yours.
  6. Review purchase history, trade history, Community Market listings and inventory. Note anything you did not do.
  7. Check your Steam Family settings and the device list on the Steam Guard page for anything you did not add.
  8. Expect a 15-day trade and market hold after these changes. It protects you.
  9. Open a ticket at help.steampowered.com ("My account was stolen") with dates and what was taken.

Discord#

  1. Change the password (User Settings → My Account). This also ends existing sessions and invalidates stolen tokens.
  2. User Settings → Devices → Log out all known devices.
  3. Turn two-factor on, or reset it to a fresh authenticator setup. Store the new backup codes off the PC.
  4. User Settings → Authorized Apps: remove anything you do not recognise.
  5. Check your email, phone, username, connections and payment methods, and any servers you own (bots added, roles changed, webhooks created).
  6. Delete the scam messages from your DMs where you can, and report the account takeover at support.discord.com.

Clean the PC#

A full reinstall of Windows is the only way to be sure. These programs give a remote page read and write access to files, so a scan cannot prove they left nothing behind.

  1. Back up documents and photos only, not programs, shortcuts or .exe files.
  2. Make Windows install media from a clean computer with Microsoft's Media Creation Tool.
  3. Reinstall and format the drive. Reinstall programs from official sources only.

If you cannot reinstall straight away:

  1. Boot into Safe Mode with Networking.
  2. Run full scans with Malwarebytes and the ESET Online Scanner, or a similar pair.
  3. Look for the files in Host detection: stray steam.exe copies in C:\Windows\, unexpected WebView2 or Electron apps that pose as Steam, and recently installed apps you do not remember in Settings → Apps.
  4. Check Startup apps, Task Scheduler and HKCU\Software\Microsoft\Windows\CurrentVersion\Run for entries you do not recognise.
  5. Plan the reinstall anyway.

Do not sign in to anything on the PC until it is clean.

Everything the browser remembered#

Assume every saved password, cookie and autofill entry on that PC was taken.

  1. Change passwords from a clean device, in this order: email, banking and payment apps, crypto exchanges, other gaming accounts (Epic, Battle.net, Riot, EA, Ubisoft), social media, shopping, then the rest.
  2. Use "sign out everywhere" where a site offers it, because stolen cookies keep working until the session ends. Google, Microsoft, Apple and most banks have this option.
  3. Turn on two-factor sign-in everywhere you can.
  4. If you reused a password anywhere, change it there too.

Crypto wallets#

If the PC had wallet extensions (MetaMask, Phantom, Coinbase Wallet) or seed phrases stored on it:

  1. On a clean device, create a new wallet with a new seed phrase.
  2. Move all funds to it straight away.
  3. Abandon the old wallet for good, and never import its seed phrase again.

If you sent money to the casino#

The money is almost certainly gone. Report it to your local police and to reportfraud.ftc.gov (US) or Action Fraud (UK), with the transaction hashes. Ignore anyone who offers to recover it for a fee. That is a second scam aimed at the same victims.

Checklist#

  • PC offline
  • Contacts warned
  • Email: password, sessions, two-factor, recovery details, forwarding rules
  • Steam: password, deauthorize devices, Steam Guard, API key revoked, trades reviewed, ticket opened
  • Discord: password, devices logged out, two-factor, authorized apps cleared, ticket opened
  • PC reinstalled (or scanned now and reinstall planned)
  • Saved passwords changed, starting with money and email
  • Crypto moved to a new wallet

How we did this#

  • Images. Parsed byte by byte, checked for embedded payloads and decoded the QR code. Re-encoded for this page with metadata removed and the QR code pixelated.
  • Infrastructure. WHOIS and RDAP, passive DNS, certificate transparency, urlscan.io, VirusTotal and ThreatFox.
  • Live sites. Fetched over Tor, read-only (GET and HEAD). We never submitted a form, signed in, registered or ran the sites' scripts.
  • Malware. The 16 programs were downloaded into an isolated analysis VM and analysed statically by CORD's research pipeline: disassembly, call graphs, resource and archive extraction, string recovery. Nothing was executed.

Limits#

  • We did not see what the fake sign-in box sends, because we did not run its script.
  • The second-stage program inside the WebView2 samples, and four of the five installers, were analysed only partly.
  • The casino's backend and deposit wallets were offline or absent from archived pages.
  • How the account owner's PC was first infected is unknown without access to it.
